🧪 Testing Instructions

  1. Ensure both servers are running:
    • npm run server in Terminal 1 (WebSocket server)
    • npm run dev in Terminal 2 (Vite dev server)
  2. Click any 2-3 links above to open multiple browser tabs/windows
  3. Test the following features:
    • Drawing sync: Draw in one tab, see it appear in others
    • Cursors: Move mouse, see colored cursors in other tabs
    • Roster: Check the online users panel (top-right)
    • Tools: Change colors/widths, use eraser
    • Undo/Redo: Press Ctrl+Z/Ctrl+Y (currently local only)
    • Room isolation: Team A and Team B shouldn't see each other
  4. Close a tab and watch the roster update in remaining tabs
